# Bank Management System

A simple Bank Management System developed using Python.

## Features

- Create a new bank account
- Login to an account
- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Store account data

## Technologies Used

- Python
- JSON
- Git
- GitHub
